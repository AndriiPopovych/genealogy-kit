# Зміни комплекту

## Ще не випущено

Вступ README та лендінг подано як особистий досвід двох родинних досліджень. На сайті знахідки передують опису підходу; матеріали й згорнута інструкція запуску доступні наприкінці.

README узгоджено з лендінгом genealogy-kit: спільне пояснення комплекту, посилання на сайт і ZIP репозиторію, готовий стартовий запит та чітке розмежування безкоштовного комплекту й сторонніх сервісів. Лендінг розробляється окремо від дослідницького комплекту.

Перший запуск починається з вільної розповіді користувача: агент пояснює цінність повних відомостей, уточнює й сам оформлює INTAKE.md. Додано єдиний сценарій вступної розмови, підготовку FamilySearch та рекомендації доступу до потрібних інструментів. Стартові шаблони й продовження враховують перерву посеред опитування; ручне заповнення анкети не потрібне.

Комплект перенесено в єдиний корінь майбутнього репозиторію public/. Додано CONTRIBUTING.md і режим розробки в AGENTS.md. Версії надалі ведуться комітами та тегами, без номерних копій коду в репозиторії. Уточнено .gitignore: синтетичні приклади не приховуються правилами для приватних кореневих каталогів. Генеровані dist/ та build/ виключено з Git.

## 3.0.0-local — 09.11.2026

Локальний кандидат випуску; ліцензію не визначено, не опублікований.

Узгоджено старт і повернення, SEARCH та контрольні точки. Додано структурну перевірку реєстрів і генерований покажчик без генеалогічних рішень. Завантажувачі перевіряють файл і кеш; приймання працівників має долю кожної знахідки. Оновлення відбувається через резервну копію, legacy-діагностику й ручне зіставлення. Чистий пакет збирається за allowlist. Умовні модулі покажчиків, видань, зовнішнього дерева та вхідних контейнерів мають синтетичні приклади.
