# genealogy-kit — матеріали для родинного дослідження з AI

Я досліджував свій рід і рід дружини разом з AI. У процесі зібрав інструкції, шаблони й інструменти, які допомагали організувати роботу, і виклав їх тут у відкритий доступ. Кожна окрема копія комплекту призначена для дослідження однієї родини. Дані та стан дослідження зберігаються у звичайних локальних файлах. Версія — у [VERSION](VERSION), зміни — у [CHANGELOG.md](CHANGELOG.md). Готове дерево чи GEDCOM не потрібні, але можуть бути початковими матеріалами.

Основний принцип: аргументовані `accepted_working` дозволяють рухатися далі з видимою невизначеністю. Прочитання документа, тотожність людини й спорідненість оцінюються окремо; валідатор не встановлює предків.

Для вдосконалення самого комплекту працюйте безпосередньо в цьому репозиторії за [CONTRIBUTING.md](CONTRIBUTING.md). Версії фіксуються Git-тегами; дослідження родини ведіть в окремій копії.

## Як почати

1. Завантажте [ZIP репозиторію](https://github.com/AndriiPopovych/genealogy-kit/archive/refs/heads/main.zip) (або на GitHub: **Code → Download ZIP**) і розпакуйте в окрему папку для однієї родини. Реєстрація на GitHub не потрібна. Копіюйте саме фактичну назву розпакованої папки у вашому файловому менеджері. Не копіюйте чуже дослідження.
2. Відкрийте цю папку в агенті й передайте [START_PROMPT.md](START_PROMPT.md). Попередньо заповнювати файли не потрібно.
3. Розкажіть агенту, що знаєте про родину й що хочете з’ясувати. Надайте якомога більше наявних доречних деталей: навіть приблизна дата, прізвисько чи підпис на фото можуть змінити пошук. Агент поставить уточнювальні запитання й сам збереже відповіді в [INTAKE.md](INTAKE.md). «Не знаю» і суперечливі спогади теж корисні.

Готовий перший запит після відкриття папки в агенті:

> Прочитай START_PROMPT.md у цій папці й почни дослідження моєї родини за його інструкціями. Допоможи мені розповісти те, що я вже знаю, та визначити перше запитання для пошуку.

Під час першої розмови агент також допоможе підготувати роботу: попросить зареєструвати безкоштовний акаунт [FamilySearch](https://www.familysearch.org/) або ввійти в наявний і залишатися в системі під час дослідження на власному комп’ютері. Для самостійної роботи агента рекомендовані доступ до папки дослідження та керування потрібним браузером; додаткові дозволи залежать від конкретного завдання. Паролі вводите тільки ви. [Як проходить перший запуск](guide/first_start.md).

**Повернення після перерви:** [RESUME_PROMPT.md](RESUME_PROMPT.md). На старті агент один раз пропонує доступну паралельну роботу; вибір і ліміти зберігаються для наступних хвиль. [PARALLEL_PROMPT.md](PARALLEL_PROMPT.md) також вмикає командний режим за вашим дорученням. Git, акаунт, команда й Python не є передумовами дослідження.

## Що всередині

- `data/` — головні P/S/C/L, історія CHANGE й фактичні пошуки SEARCH; [контракт](templates/records.md).
- `state/` — короткий стан, питання, навігація, черга та хроніка; це не друга база фактів.
- `originals/` — незмінні отримані файли; `working/` — похідні; `transcripts/` — прочитання.
- `workers/` — окремі спроби працівників; приймає один координатор.
- [Повністю вигаданий приклад](examples/synthetic/README.md) показує переказ, конфлікт, робочий зв’язок і виправлення.
- [Зрозумілі оновлення дослідження](guide/research_updates.md): короткі результати окремих питань і PDF на змістовних етапах: дерево, докази, статистика та невизначеності. HTML — додатковий формат. [Коли агент продовжує й зупиняється](guide/research_control.md). [PDF-приклад](examples/synthetic/exports/family-report/report.pdf) · [Додатковий HTML-приклад](examples/synthetic/exports/research-update/index.html).
- [Маршрути джерел](guide/source_directory.md), [читання](guide/reading_records.md), [інструменти](guide/tools_and_memory.md), [видання для родини](guide/family_presentation.md).

## Вимоги й межі

Ручний режим потребує лише текстового редактора. Агенту потрібні перевірені можливості читати й записувати файли. Python 3 потрібний для необов’язкових локальних інструментів; [генератор PDF](guide/pdf_reports.md) додатково потребує reportlab і локального шрифту з українськими літерами; завантажувачі потребують Pillow і curl. Зір потрібний для прочитання сканів, браузер — за потреби входу користувача. Swift/PDFKit — лише macOS; Poppler — окрема альтернатива, яку треба перевірити у своєму середовищі. Без запису агент повертає готовий текст і називає, хто має його зберегти. Без зору скан не стає `reviewed`.

Локальне зберігання не гарантує локальної обробки моделлю. Витрати й приватність залежать від обраних інструментів. Конкретні агенти й Orca — необов’язкові адаптери. Поточний обсяг — українські родини в мінливих історичних юрисдикціях, з навігацією до суміжних країн та США. Повної світової методики чи перевіреної підтримки всіх ОС/агентів не заявлено.

## Публічний комплект і приватна копія

Робоча папка після заповнення приватна. Випуск складається в порожній папці за явним переліком: [підготовка пакета](guide/release.md). `proposals/`, `reviews/`, робочі дані, сімейні файли та резервні копії до нього не входять. Правила [приватності матеріалів](guide/family_presentation.md) допускають історичні відомості про `unknown` зі встановленим народженням до 1925 року без окремої перевірки життя; рік не змінює статус на `deceased`.

Оновлення старої копії: [guide/upgrade.md](guide/upgrade.md). Не замінюйте заповнені INTAKE/data/state новими порожніми шаблонами. Комплект поширюється за [ліцензією MIT](LICENSE); [межі її застосування](LICENSE_STATUS.md) відділяють комплект від родинних даних і сторонніх матеріалів.
