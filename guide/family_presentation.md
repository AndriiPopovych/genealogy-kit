# Матеріали для родини

Видання створюють за запитом, з визначеною темою, аудиторією й датою зрізу. Повнота стосується цієї теми, а не всіх нових осіб у базі. Спочатку дві статичні картки та перевірка читабельності на потрібному носії; універсальний генератор сайта не потрібний.

## Окремі позначення

Тип джерела (original_record / family_testimony / derivative_index тощо) і статус рішення (candidate / accepted_working / supported / unresolved / rejected) незалежні. «Є документ» не означає доведеного предка. Окремо покажіть прочитання, тотожність та спорідненість; найслабший потрібний перехід лишається видимим.

Картка: хто; зв’язок із початковою особою; слабкий місток; висновок і межі; S/C/L із точним локатором; читабельний фрагмент та посилання на повний кадр. Якщо кадр містить приватні дані, давайте позначену відредаговану похідну копію. Бічна гілка пояснює шлях до теми. Цитати лишаються мовою джерела. Кожне істотне фактичне твердження про людей і джерела має реєстрову підставу.

living і unknown захищаються за замовчуванням; сам рік народження не визначає deceased. Погодьте мінімум даних для конкретної аудиторії. Чутливі поля змінюйте тільки на похідній копії; оригінал незмінний. Локальне створення не означає публікації або дозволу на додаткову хмару.

## Маніфест видання

Шаблон — [export_manifest.json](../templates/export_manifest.json). У exports/<назва>/manifest.json запишіть дату зрізу, тему, аудиторію, record_refs (типізовані S/C/L/P із SHA-256 канонічного JSON запису: UTF-8, sort_keys=True, separators=(",",":"), ensure_ascii=False), input_files (шлях/SHA використаного зрізу), files (шлях/SHA результату), privacy_revision, local_status та deployed_status. Хеші файлів потрібні для відтворення, record_refs — для адресної залежності.

Після CHANGE запустіть read-only affected_records.py або вручну пройдіть C→S/L→C/depends_on. У зачепленому маніфесті координатор ставить local_status=outdated до перевірки. Незалежне видання не скасовується. Локальне виправлення не оновлює deployed_status: для опублікованої копії окремо outdated до підтвердженого зовнішнього оновлення. Генератор не приймає генеалогічних рішень.

[Дві синтетичні картки](../examples/synthetic/exports/cards/cards.md) показують різні типи джерел, невизначеність та адресу повного матеріалу. Макет перевіряється локально; читабельність на друці чи іншому пристрої перевіряйте для конкретного каналу. Бюджет медіа визначає канал, не загальна заборона великих кадрів.
