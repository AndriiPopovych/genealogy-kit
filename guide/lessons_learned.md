# Короткі уроки

Рухайтеся від найближчого відомого покоління. Сімейне свідчення — джерело з власним походженням; відсутність акта народження не забороняє обґрунтованого робочого переходу. Правила доказів — [AGENTS.md](../AGENTS.md), приклад — [synthetic](../examples/synthetic/README.md).

## Чекліст онлайн-копій

Для поточного питання перевіряйте доречні канали: е-архів установи; Вікісховище за точним шифром; Вікіджерела «Архів:…»; усі доречні колекції й інтерфейси FamilySearch регіону; AGAD; інші конфесії; сусідні парафії; консисторські й деканатські примірники. Зберігайте точну адресу, дату, метод і результат у SEARCH. Не кожний канал доречний кожній справі: причину незастосовності теж позначайте.

Розрізняйте `not_checked`, `catalog_only`, `images_available`, `access_blocked`, `searched_no_match`. «Не знайдено в перелічених каналах станом на дату» — межа пошуку, а не загальне «не оцифровано». 403, порожній OCR і кілька кадрів не доводять відсутності документа. Чекліст не гарантує повноти інтернету.

Фактичне покриття зберігайте один раз у SEARCH; навігацію — у source_map, призначення — у queue. Змістовний повтор має причину. [Маршрути](source_directory.md) — датована навігація, не гарантія доступу.

Контрольна точка потрібна до обриву, не тільки наприкінці. [Повернення](../RESUME_PROMPT.md), [приймання працівників](parallel_research.md) та [інструменти](tools_and_memory.md) містять процедури без дублювання тут. Знання з іншої родини не переноситься як факт цієї.
