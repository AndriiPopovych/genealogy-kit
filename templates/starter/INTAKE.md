# Початкові відомості про родину

Цей файл веде агент із вашої розповіді та відповідей. Перед першим запуском заповнювати його не потрібно: просто розкажіть усе доречне, що вже знаєте про родину. «Приблизно», «зі слів бабусі» та «не знаю» — корисні відповіді. Агент уточнить незрозуміле, сам збереже відоме й надалі доповнюватиме файл. Порядок розмови — [guide/first_start.md](guide/first_start.md).

## Початкові орієнтири — зі слів користувача

- Початкова особа (ім’я або псевдонім):
- Одне питання / гілка, з якої почати:
- Відомі люди, їхній зв’язок, місце й приблизний час (можна «не знаю»):
- Звідки це відомо, чи свідок бачив подію, переповідає або не пам’ятає походження:

Агент заповнює лише отримане й позначає невідоме; повнота цього файла не є умовою початку роботи. Якщо людина вже надала розповідь або дерево, спочатку використати їх, а не повторювати опитування.

## Люди й зв’язки

Агент додає рядок для кожної відомої людини. Для жінок окремо зазначає дівоче прізвище, прізвища в різних шлюбах і те, що лишається невідомим.

| Людина та варіанти імені | Зв’язок із початковою особою | Дати з рівнем точності | Місця й події | Хто повідомив або який документ |
|---|---|---|---|---|
|  |  |  |  |  |

Якщо зв’язок неоднозначний, запишіть словами: «мама називає його двоюрідним дідом, точна схема невідома». Не підганяйте розповідь під готовий родинний термін.

## Поселення

- Назва, як її вимовляють у родині:
- Інші написання й давня назва:
- Найближче відоме місто, річка, залізнична станція:
- Для якого року відоме проживання:
- Це місце народження, проживання, шлюбу, поховання чи лише припущення:
- Відомі церква, парафія, конфесія, мова документів:
- Переїзди, евакуація, виселення, еміграція — зі словами оповідача:

## Родинні свідчення

Для кожної розповіді: хто повідомив, коли, що пам’ятає особисто, що почув від іншого, що припускає. Різні версії збережіть поруч.

Корисно запитати про братів і сестер, повторні шлюби, домашні прізвиська, сусідів, місце весілля, кладовище, роботу, військову частину та родичів, у яких лишилися документи. Ставте відкриті запитання: «Що ви пам’ятаєте про його батьків?», а не «Його батька звали Петром?».

## Побажання

- Режим: один відповідальний виконавець (типово) / явний паралельний.
- Межа поточного питання:
- Ресурсний бюджет (час, обсяг завантажень, витрати), умова збереження паузи:
- Лише онлайн чи також дозволено готувати офлайн-маршрут без надсилання:
- Дозволені зовнішні сховища **цієї самої родини**, точні адреси та обсяг доступу:
- Чинні індивідуальні обмеження (із датою зміни):


- Які матеріали мають лишитися лише локально:
- Чи дозволені платні послуги: за замовчуванням — лише після окремого погодження.
- Завантаження публічних архівних сканів: за замовчуванням дозволене без окремих запитів. Обмеження, якщо потрібні:
- FamilySearch: рекомендацію повідомлено коли; акаунт є / немає / невідомо; вхід підтверджено коли й у якому дозволеному браузері або відкладено:
- Дозволений доступ до папки, браузера та потрібних програм; що перевірено й які обмеження:
- Публікація дерева: за замовчуванням — не дозволена.

Не вписуйте паролі, повні номери сучасних документів або інші зайві ідентифікатори живих людей.

Для зовнішніх матеріалів living і unknown захищені за замовчуванням. Рік народження не визначає статус померлого. Локальне дослідження не є згодою на публікацію чи додаткову хмарну обробку. Контракт зовнішнього дерева — [guide/external_tree_export.md](guide/external_tree_export.md).
