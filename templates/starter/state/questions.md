# Питання й пріоритети

| ID | Питання й межа | P/L | Статус | Відомо від родини, включно «не знаю» | Що може змінити відповідь | Наступна дія / причина питання | Результат S/C/L/SEARCH |
|---|---|---|---|---|---|---|---|

Стани: open / investigating / waiting / answered / deferred. Нове сімейне свідчення, виправлення прочитання, методичне побажання й зміна меж — різні події. Не повторювати вже дану відповідь без підстави. Зміну меж записати з датою, попереднім обсягом і зачепленими J; старий SEARCH зберегти.

Для активних маршрутів додавайте під таблицею користь, конкретну зачіпку, межу перевірки й умову повернення за templates/research_route.md. Для deferred обов’язкові причина й тригер поновлення. Відкладення через низьку користь пошуку не є спростуванням родовідного зв’язку; SEARCH зберігає лише виконаний обсяг.
