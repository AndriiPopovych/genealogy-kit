# Журнал сесій

Для кожної завершеної сесії додати дату, головне питання, нові джерела, рішення та виправлення, точний обсяг перегляду, змінені файли й наступні три дії. Повний журнал запитів зберігати в `data/searches.jsonl`.

Зрозумілий підсумок за `guide/research_updates.md`: що змінилося проти попереднього оновлення (дата/посилання або перший зріз), чому це важливо для родини, підстави S/C/L з локаторами, головна невизначеність і наступний пріоритет. Локальні результати позначайте темою/питанням; загальний підсумок посилається на них. Для PDF та HTML додайте шлях і дату зрізу. Збережіть рішення про продовження/зупинку, його причину та умови повернення до відкладених напрямів. Без знахідок чесно назвіть оглянутий обсяг та SEARCH ID.
