# Навігація джерел

Кандидати й структура книг, а не другий журнал фактичного огляду. Канонічне покриття — data/searches.jsonl.

| document_key | Назва / частина / роки | Шифр і походження | DGS / URL / місцевий файл | Структура, нумерації та кандидати | SEARCH IDs |
|---|---|---|---|---|---|

Один DGS може містити кілька справ: document_key визначає саме книгу/частину. Кадр, аркуш та акт — різні координати. Перед призначенням перевірити SEARCH і вже прийняті файли. Повтор має repeat_of та repeat_reason; відсутні інтервали не виводяться з кількості рядків.

Необов’язковий покажчик для багаторазового використання книги — [шаблон](../templates/book_index_notes.md).
