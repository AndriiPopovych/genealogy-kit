# Необов’язковий покажчик книги

Запуск лише коли книга потрібна кільком Q/поколінням або малий пілот показав користь. Для одного акта досить SEARCH. Покажчик — похідна навігація, не незалежне свідчення і не доказ повноти.

Для кожного рядка book_index.tsv зберігайте document_key, кадр/аркуш/акт окремо, рік/розділ, буквальні імена/ролі, статус і поля огляду, шлях до транскрипції й локатор. Порожнє поле — невідоме, не нуль. OCR позначайте machine_ocr_unverified. Кожен рядок має повертати до матеріалу.

Контрольний підсумок: заявлений у джерелі річний підсумок актів; реально наявні сторінки; унікальні акти; дублікати рядків/кадрів; пропуски; причина різниці; SEARCH IDs. Число рядків не дорівнює числу актів. Повторне використання для іншого поля потребує окремого SEARCH, якщо поле ще не читали. Не поширюйте reviewed на всю книгу. Масштабування індексу й пороги вікових розбіжностей лишаються X03.
