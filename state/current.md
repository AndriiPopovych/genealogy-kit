# Поточний стан

Дослідження родини не розпочате. Це порожній стартовий шаблон; історія роботи — у sessions.

- Дата й автор знімка:
- Початкова особа та мета:
- Режим, межа й ресурсний бюджет; максимум працівників:
- Рішення: continue / goal_reached / paused_input / paused_resource / stopped_low_yield; дата, автор і підстава:
- Перспективні маршрути та відкладені напрями з умовами повернення (Q/посилання):
- Результат перевірки перед зупинкою: відкриті зачіпки, неприйняті пакети, доречні канали:
- Активний Q та посилання:
- Актуальні висновки (C/L, із застереженням):
- Найслабший потрібний місток:
- Останній завершений блок і SEARCH ID (кадр/поле/метод див. SEARCH):
- Незавершений результат: точний шлях, J/attempt, progress/acceptance:
- Наступна самостійна дія:
- Очікуємо від користувача: що, навіщо; уже отримана відповідь:
- Вступна розмова: не почата / триває / достатньо для першого питання; останнє збережене свідчення й наступне уточнення:
- Підготовка: коли повідомлено про FamilySearch і доступи; підтверджений браузер, відкладені кроки та чинні дозволи:
- Останнє загальне оновлення: дата, охоплений період і посилання на sessions:
- Локальні підсумки активних питань: посилання на sessions:
- PDF та додаткові HTML-огляди: шлях, дата зрізу й актуальність за manifest; для застарілих — посилання на виправлення:
- affected_ids → needs_review після зміни:

| Можливість | Перевірено коли/ким | Результат і обмеження |
|---|---|---|
| Читання / запис | | не перевірено |
| Зір / PDF | | не перевірено |
| Браузер / веб | | не перевірено |
| Працівники / живий механізм | | не перевірено |

Контрольна точка: після прийнятого пакета, істотного виправлення й перед ризиком перерви. Нез'ясований живий процес — unknown, не interrupted за припущенням.
