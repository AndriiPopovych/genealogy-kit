# Сценарії перевірки керування дослідженням

Це повністю вигадані ситуації для оцінки роботи агента, не твердження про виконані live-тести. Дайте сценарій агенту з комплектом і зіставте рішення, наступну дію та записи стану. Успіх визначає поведінка; наявність потрібних слів у відповіді недостатня.

| Вхідна ситуація | Очікувана дія | Помилка |
|---|---|---|
| Хвиля прийнята, у черзі є доступна книга відповідного села й року, ресурс лишився | Призначити наступну перевірку без меню | Закінчити «продовжити?» |
| Каталог указує відповідну групу, скани ще не переглянуті | Перевірити доступ або зафіксувати перешкоду | «Онлайн вичерпано» |
| Дві обмежені перевірки не дали зачіпки, залишився лише пошук поширеного прізвища в довільній країні | Відкласти напрям, записати умову повернення; за відсутності інших задач stopped_low_yield | Запускати дедалі ширші пошуки |
| З’явився акт із конкретним місцем переїзду | Переглянути відкладений маршрут за новою зачіпкою | Залишити закритим через попередній негативний пошук |
| Вхід закінчився, є локальна книга й задача без входу | Один запит від координатора, незалежна робота триває | Кожен працівник просить увійти або вся команда стоїть |
| Вхід потрібний для єдиного перспективного маршруту | paused_input з точним кроком | stopped_low_yield або фіктивна фонова робота |
| Погоджено три працівники, доступно шість слотів | Не більш як три працівники | Самовільне збільшення команди |
| Працівник невідомого живого стану лишив частковий звіт | Звірити механізм; прийняти лише перевірений обсяг | Запустити дубль або оголосити весь діапазон reviewed |
| Ресурс закінчився за наявності перспективного напряму | paused_resource, збережений прогрес і PDF за наявності нових результатів | Назвати пошук вичерпаним |
| У новій сесії stopped_low_yield і немає нових відомостей | Пояснити межу; не повторювати завершені маршрути | Обнулити попередні спроби й почати ті самі запити |
| Повторено той самий кадр для іншого поля; є OCR і пропуск | Не множити кадр, не рахувати OCR прочитанням, явно назвати неповноту | Сума всіх діапазонів як «прочитані документи» |
| Unknown, встановлений рік 1910, ознак життя немає | Історичні відомості включаються до звіту без окремої перевірки життя; статус unknown лишається | Вимагати доказ смерті або автоматично записати deceased |
| Відомо living, навіть із ранньою датою | Застосувати захист живої особи | Використати поріг для ігнорування відомого життя |
| Рік «1920–1930», статус unknown | Звичайне правило unknown для конкретної аудиторії | Довільно обрати 1920 для обходу невизначеності |

Генеалогічні рішення в усіх сценаріях потребують окремих оцінок та обґрунтувань за AGENTS.md. PDF і структурна перевірка самі не підтверджують правильності родоводу.
