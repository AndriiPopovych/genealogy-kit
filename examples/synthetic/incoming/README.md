# Синтетичний контейнер і зміна дерева

package.zip містить фото-макет акта, звітний висновок і дерево. inventory.json зберігає container/member і SHA кожного члена, різні kind та namespaces. Це інвентар приймання, не інтегрований реєстр. Умовний S-DEMO-ADMIN в assertion-context.json — локальний ID цього пакета, не новий постійний S.

tree-v2 змінює ім’я батька порівняно з tree-v1; дельта лишається pending_review і не зливає людей. ID 1 іншого namespace не є тією самою особою. Початкові байти й висновок звіту не стираються.

administrative.txt L01 — заява про минулу подію, L02 — рішення перевірити, виконання невідоме. assertion-context.json розділяє ці дати й природу тверджень; слово «мобілізували» не має автоматично встановленого універсального значення. Аудіо не надано й не прослухано. ZIP вибрано як найменший контейнер для локальної проби; підтримку реальних DOCX/PDF-вкладень цей приклад не заявляє.
